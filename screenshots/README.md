# Dashboard Screenshots

Export your Power BI report pages as images and place them in this folder.

Recommended filenames:

- overview.png
- win-loss-ratio.png
- industries-overview.png
- trend-analytics.png
- pipeline-trends.png
- won-key-influencers.png
- days-key-influencers.png
- percent-off-key-influencers.png
- decomposition-analysis.png

After adding `overview.png`, you can show it in the main README with:

```markdown
![Dashboard Overview](screenshots/overview.png)
```
